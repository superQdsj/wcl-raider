# 复盘报告模板

按下面的结构写。各节篇幅随问题的严重程度调整：没有问题的维度一两句带过，把篇幅留给真正影响结果的问题。每条结论都要能追溯到数据（时间点、波次、数字），并分别标注事实与归因的置信度。

```markdown
# {副本} +{层数} 复盘 —— {结果}（{官方用时} / {限时}）

> 报告：{链接} · {日期} · {地区}
> 阵容：{坦克} / {治疗} / {输出1} / {输出2} / {输出3}
> 词缀：{词缀}

## 一句话结论
{这一把主要赢在/输在哪里。例如（虚构）："超时 40 秒；扣除罚时后的用时与同层高分持平，差距全部来自第 2 个首领的一次灭团和 4 次死亡（罚时 20 秒）。"}

## 最值得改进的 3 件事
只收中、高归因置信度的问题，按"能省多少时间 / 能降低多少翻车风险"排序。不足 3 件就写 2 件，不要凑数。每条按以下格式：

1. **{问题}**（负责人：{玩家/职责/全队}；事实置信度：{高/中}；归因置信度：{高/中}）
   - 定位与事实：{第 N 波 / 首领、m:ss、技能；分子/分母数字；对比样本数与范围}
   - 判断：{主因 + 贡献因素}
   - 后果：{罚时、缺席（回归列）、失败尝试，或治疗压力与风险；能估算的写区间}
   - 下次怎么做：{谁、什么信号出现时、做什么}
   - 复验：{下一把检查哪个指标}
2. …

## 时间都去哪了
- 余量与差距：{距限时 / +2 / +3 各差多少}
- 扣除罚时后的用时：{X}，对比同层高分中位数 {Y} → {问题在死亡 / 问题在节奏 / 两者都有}
- 首领战与小怪用时（与高分记录对比，注明样本可比性）
- 长间隔、灭团或重打：{哪一波、多久、核实后的原因}
- 嗜血时机：{用在了哪几波，是否覆盖最危险的波次}

## 死亡复盘
每次死亡（或每串连续死亡）一行。团灭要指出第一张倒下的多米诺骨牌，后续死亡标为连锁。

| # | 时间/波次 | 死者 | 致死 | 归因 | 关键证据 | 缺席（回归） | 怎么避免 |
|---|---|---|---|---|---|---|---|

## 机制与承伤
- 本可避免的伤害：{技能、谁、次数或受伤段，与高分记录的归一化对比}
- 需要靠治疗/减伤硬吃的伤害：{技能、波次，建议的减伤/团减安排}
- 待核实的候选：{来自 score 的暴露偏离候选，尚未核实的}

## 打断与驱散
- 漏断最多的关键技能及集中出现的波次；分工问题还是容量问题（`interrupts --pull`）
- 纯打断与控制的分工；有没有重复或浪费的打断
- 驱散：有没有可驱散的减益拖得太久

## 评分（数据分 v2）
团队与个人评分表、依据的判断数量；N/A 和"不发布"照实写出原因（格式见 `scoring.md`）。

## 个人表现
只写深挖过的人，每人 2–3 条，先说做得好的，再说可改进的。没有深挖的人写一行汇总，或"证据不足，未作个人诊断"。
### {玩家}（{专精}）
- 做得好：…
- 可改进：…

## 下一把执行清单
- [ ] {从"3 件事"提炼成可以直接在语音里布置的短句，例如（虚构）："第 6 波 4 只施法者按星/月/方块/三角标记各断一只"}

## 数据口径与不确定性
- {不可用或存疑的指标（样本过小、计数不一致、输出截断等），未核实的机制，查不到的数据}
```

## 写作要求
- 用中文，技能名用游戏内中文名，必要时附技能 ID。
- 具体：写"第 N 波 m:ss–m:ss 在某地面技能里停留 6 秒（受伤段 7 跳，单次约 50 万）"，不要写"注意走位"。
- 给队伍的口令优先引用波次和读条信号，不用绝对时间。游戏内计时和 WCL 时间之间还隔着累计罚时。
- 区分事实、推断和建议；推断要附理由，拿不准的写"可能"，并说明怎么验证。
- 不评价路线本身的好坏，除非数据明确显示某个选择直接导致了灭团或大量时间损失。
- 语气像队友之间复盘：直接、对事不对人，先肯定做得好的地方。

## 交付前自检
- [ ] 死亡总数与死亡复盘表的行数一致；被截断的输出已补查。
- [ ] 3 件事里每条都核实过关键事件窗口，归因置信度为中或高。
- [ ] 没有把"未战复"当作缺席到波次结束；缺席时长以"回归"列为准。
- [ ] 写"有减伤没交"之前，可用性表显示"可用"。
- [ ] 百分位样本不可靠时，没有拿它下结论；治疗没有按 HPS 评价。
- [ ] 分数和正文一致：3 件事的负责人，相关维度 ≤ 7.4，或者写明了理由。
- [ ] 没有因为连锁死亡追究个人，也没有把一条因果链拆成多个问题重复计算。
