# 职业应对手段速查（正式服 午夜 12.1.x）

用来解释 `tactics` 找到的技能"为什么能这样用"、以及给没有某职业的队伍找替代。资料来自 Wowhead 当前数据，并对照 warcraft.wiki.gg 的补丁记录，核对日期 2026-11-06。**新补丁可能改天赋**：结论要写进报告前，用 `wcl spell <ID>` 或 Wowhead 再确认一次。

分类：**自解** = 清除自己身上的减益；**驱散** = 给队友（或自己）驱散；**免疫** = 阻止减益上身/免疫伤害；**解控** = 解除或免疫定身、减速、昏迷、恐惧等。

## 个人减伤怎么读（职业专题的工具箱用）
减伤不解减益，只是"顶住伤害"。日志里用完照样被打中是正常的，被打中的那个技能就是它在顶的东西。下面写的是性质，具体数值以 `wcl spell <ID>` 为准。

## 已移除或仅 PvP（不要写进建议）
虚空行走、神圣守卫（12.0 移除）；防护恐惧结界（已不在游戏中）；轻驰飞翔（12.1 起 PvP）；根基图腾、治疗绷带、转瞬即逝、反转魔法（PvP 天赋）。
