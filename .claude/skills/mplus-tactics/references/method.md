# 应对技巧复盘方法

## §1 工具做了什么
`wcl tactics` 先选出每名玩家的**额外技能**：分类表里已知的功能技能（驱散、自解、免疫、反射、减伤、外部减伤、团队减伤、解控、位移、控制、消耗品、战复），加上**低频**（CPM ≤ 1.5）且几乎不贡献伤害（< 2%）和治疗（< 4%）的施法。打断另有 `interrupts` 命令，这里只列次数。

然后还原**每一次使用**：
- 作用对象：施法目标是队友就看队友，否则看施法者自己；团队类（团队减伤、群体驱散、狂风图腾等）看全队。
- 情境：作用对象身上的敌方减益；使用后 2 秒内上身的减益（预判）；使用前 3 秒被哪些敌方技能打中；前 4 秒、后 2 秒的敌方读条/施放；使用前的血量与前 3 秒承伤。
- 直接效果：
  - **驱散**：WCL 驱散事件，和施法对上（含清毒图腾、牺牲祝福这类触发驱散；对不上施法的驱散单独记在施法者名下）。
  - **推断消除**：使用后 0.4 秒内，作用对象身上的某个减益在"完整持续"的 85% 之前消失，且不是驱散、死亡或"同时结束"。完整持续 = 未被驱散、未随死亡消失的那些的 90 分位；Wowhead 写的持续时间更长时用它（所以几乎总被驱散的减益也不会被算成"本来就很短"）。**同时结束** = 0.3 秒内另一名玩家也失去同一减益，视为机制自己的循环，不归因给任何人。不在已知移除类分类里的技能，要求同一减益至少被消除 2 次、并且身上有这个减益时一半以上的使用都让它消失，否则当成巧合丢掉。
  - **免疫 / 反射**：使用后 12 秒内，作用对象对敌方技能的命中结果是 IMMUNE（hitType 10）或 REFLECT（hitType 9）。多个候选时优先免疫/反射/解控/自解类，其次减伤类，再看哪个技能"每次用完都出现免疫"，最后取最近的一次。
- 汇总：同一技能多次使用时反复出现的敌方机制（读条、减益、伤害按**技能名**合并，所以施法 ID 和减益 ID 不同也能对上）。"倍数"= 实际伴随次数 ÷ 随机时刻也会伴随的期望次数，期望按该机制的情境窗口覆盖了多少战斗时间计算；再做泊松检验。每名玩家的表收 p ≤ 0.02 且 ≥ 2.5 倍的伴随，"敌方机制"表只收 n ≥ 3 且 p ≤ 0.002 的伴随。
- 常连用：同一玩家反复在 5 秒内接连使用两个额外技能（不论先后，括号里给出反过来的次数），例如牺牲祝福与圣盾术。
- 团队同时应对：2 秒内 ≥ 4 人都用了保命/免疫/解控类技能，或 ≥ 3 人且有人免疫/反射成功的时刻，附之前 4 秒的敌方读条。用来找"全队一起处理同一个大招"的时刻。
- 逐次情境（`--ability`）最后一列是使用后 6 秒内作用对象被哪些敌方技能命中（含被免疫/反射的）。一个"预开"的反射/免疫之后什么都没打到，可能只是没被点名，不要算作失误。
- 技能 ID：第一、二节的表里给出敌方技能的 ID（读条/减益/伤害可能是不同 ID），直接拿去 `wcl spell`。

## §2 证据强度（决定写进正文还是 `unclear`，以及怎么措辞；强/中/弱 只写在 `appendix.evidence`）
| 强度 | 证据 | 能说的话 |
|---|---|---|
| 强 | 驱散事件；免疫/反射命中；多场共识（≥ 2 场同职业同技能） | "X 用 Y 驱散/免疫/反射了 Z" |
| 中 | 推断消除（重复出现）；伴随 p ≤ 0.002 且逐次核实过时间关系 | "X 习惯在 Z 读条时开 Y"、"Y 之后 Z 立刻消失" |
| 弱 | 单次推断消除；p 在 0.002–0.02 的伴随；只出现 1–2 次 | 只能写成线索，放进"还没看清的" |

## §3 时机分类（用 `--ability` 的逐次情境判断）
- **预开**：敌方读条在使用之前（"前读条 −1.5"），减益在使用之后才上身或根本没上身（免疫）。例：读条时开法术反射、反魔法护罩、给队友自由祝福。
- **上身后解**：使用时作用对象身上已有该减益，随后消失。例：清洁术、假死清毒、石像形态、暗影斗篷。
- 职业汇总里的"时机"分布怎么翻成报告用语（上身后 / 看到 X 读条时 / 掉血时 / 冷却好就用），统一按 `class-counters.md`「个人减伤怎么读」末尾那张表。"其他"占多数时，先看"按位置"表有没有 ≥ 2 倍的读条：有就写"看到 X 读条时"，没有才写"冷却好就用"。
- **保命**：使用前血量低、前 3 秒承伤大，和特定机制无关。这类是减伤习惯，不是针对机制的技巧，除非反复对准同一个技能。
- **转移再免疫**：常连用里出现"外部减伤 → 自身免疫"（牺牲祝福 → 圣盾术）。
- **副本按钮 / 副本效果**：多个职业都用、不在职业技能里的技能。几乎每次都是全队 0.5 秒内同时"施放"的标为"副本效果"（由副本施加，例如 `藤蔓之握`，不是玩家按的，只能说明机制节点）；不同步的标为"副本按钮"（道具或特殊动作条，对应某个机制的标准解法），单独成节写。

## §4 常见误判
- **减伤之后照样被打中不是失误**。减伤、护盾、回溯（操控时间）本来就是"挨打时开"，用后 6 秒里命中它的技能，正是它在顶的伤害。只有免疫类才看"用后还被不被打中"。要说"开了没用"，得看到坏结果（死亡、掉到 20% 以下）。
- **减益提前消失不一定是玩家解的**。很多机制在离开区域、打断施法者、施法者死亡、转阶段时自己消失。"原因未识别"占多数的减益，多半是机制本身，不要硬套职业技能。
- **免疫有前提**。很多首领技能无视免疫（pierce immunity），免疫类技能也不会移除这类减益；日志里没有出现 IMMUNE 结果，就不能说"可以用 X 免疫"。
- **天赋看不到**。同一个技能在不同天赋下效果不同（见 `class-counters.md`）。从行为推断天赋时写"推断点了 XX"，不要写成事实。
- **同名不同 ID**。工具按名称合并，个别时候会把同名的两个不同技能合到一起；对证据有疑问时用 `events --ability <ID>` 分开看。
- **分类带 `*` 的是自动推断**（Wowhead 说明关键字或使用时机），可能不准；例如"破裂投掷"因为说明里有"吸收"被归成减伤，实际是打掉敌方护盾。
- **团队减伤的伴随**很容易和"开怪""首领转阶段"重合，要看逐次情境再下结论。
- **同一波怪的其他技能也会"伴随"**。驱散 A 技能时，同一波怪的 B、C 技能也在读条，所以 B、C 也会显示为伴随（例如清洁术同时"伴随"麻痹射击和同一波的恶臭喷吐、肢解）。看"身上有 n"这个通道：真正针对的机制通常是"身上有"占多数的那个。
- **装备与消耗品**（饰品、药水）也会出现在额外技能里，一般不作为职业技巧写。
- **私有光环**（private aura）和不产生减益的机制，日志里看不到，`tactics` 也看不到。

## §5 多场对照
- `--refs N` 从 WCL 同副本同层排名里取前几条带日志的记录（不足时扩大到全部层数）。前排常常是同一支队伍的多场记录：对照表会把有 ≥ 3 名相同玩家的记录归为同一支"队伍"（A、B…），每种应对标出"k/N 场（t 队）"。**只有 t ≥ 2 才算多队共识**；同一队的多场只是同一批人的习惯。
- 某个机制只有一个职业在处理，而本队没有这个职业：查 `class-counters.md` 的"谁能解什么"一节，给出替代方案，并说明替代方案没有在数据里出现过。
- 用户给了自己的记录（`--ref <自己的链接>`）：对照表里高分记录都有、自己没有的应对，就是"漏掉的技巧"，是报告里最有价值的部分。
