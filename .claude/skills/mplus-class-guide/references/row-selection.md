# 从数据挑行

目标：每一行路线、每一个「先学这四招」，都能追溯到录像里的一条强关联或一个机制事实。

## 去哪里找

`wcl tactics` 存下的每份 `<报告>-<场次>.md` 里：

| 小节 | 看什么 | 例子（红玉新生法池·武器战） |
|---|---|---|
| 一、敌方机制 → 被哪些额外技能应对 | 伴随 n/N·k倍、反射、免疫、驱散、推断消除 | 火热冲击 → 嘲讽[伴随 8/10·7.8倍] |
| 三、每名玩家的额外技能 → 典型情境 | 每个技能最常伴随的机制 | 破裂投掷 → 冰霜过载 2/3（25倍） |
| 三、常连用（5 秒内接连使用） | 组合技 | 嘲讽 → 法术反射 ×14，中位间隔 2.1s |
| 四、团队同时应对 | 全队一起处理的大招，以及反射/免疫成功 | 反射燃焰弹幕×4 |
| 七、按位置 | 哪一段用了什么、用前敌方在读什么 | 首领3 · 防御姿态 → 烈焰喷吐 100% |
| 七、敌方减益怎么结束的 | 能不能自解、谁解的 | 风暴之眼：冲锋后随后消失 |

## 分级

| 级别 | 条件 | 怎么用 |
|---|---|---|
| 必写 | 三场里 ≥2 场出现；或单场伴随 ≥5 倍且 n≥3；或有直接效果（反射/免疫/驱散/推断消除）且符合技能说明 | 路线行；最强的进 02 四招、03 专题 |
| 可写 | 单场、倍数一般，但技能说明能解释（如护盾机制配破盾技能） | 路线行，措辞保守 |
| 线索 | 只有一次、或技能说明解释不通 | 只放减益表或不写 |
| 不写 | 种族技能、饰品、药水、纯爆发技能（天神下凡之类）、坦克专属处理 | — |

伴随只说明时间上接近，不说明因果。必须用技能说明讲通「为什么」，讲不通就降级。

## 查机制事实

每个要写的机制，查齐以下几项（`wcl spell <ID>` 和 `scripts/mechanic_facts.py`）：

- **施法者**：哪种怪（`mechanic_facts.py` 的 caster 表）。路线行的信号写成「炎缚毁灭者准备读条」，而不是「读条开始」。
- **打谁**：当前目标 / 一名玩家 / 全团 / 前方锥形。「当前目标」意味着嘲讽可以改目标。
- **持续与数值**：几秒、每跳多少、结束时有没有爆炸。
- **类型**：物理/魔法系别，能否驱散，是否免疫控制（如寒冰壁垒「防止控制效果」→ 先断它）。
- **护盾**：吸收量、护盾在时有什么脉冲、破盾后果（如暴风骤雨之盾破盾全员昏迷 4 秒）。

## 分析工具的已知坑
- `class_digest`（分析末尾的汇总）会把驱散、免疫、伴随几条证据通道加在一起，数字不是施放次数；次数以第一节和逐次情境为准。
- 控制技能（昏迷、断法）的目标在分析里可能显示成自己或空；要知道「锤给了哪种怪」，用 `wcl` 查原始施法事件的 `targetID`，再看敌方身上的昏迷减益。
- 「免疫 X」标签只说明 X 的某次命中被免疫，不说明技能类型：免控技能出现在「免疫某个范围技能」里，可能只是免了它附带的击退或定身，不代表能免伤害。按技能说明的效果类型重判。
- 「驱散类型：—」是没查到，不是不能驱散；用 `wcl spell` 确认魔法/中毒/疾病/诅咒。
- 伴随强、但作用对象对不上的（技能给了小怪，机制在玩家身上），写的是「对小怪做了什么」，不是「技能解了这个机制」。

## 解释不通时先查天赋
分析说「技能 X 驱散/免疫/消除了 Y」，而 X 的基础说明做不到时，**先查这名玩家点了哪些修改 X 的天赋**（`talents.json` / 天赋树里描述提到 X 的节点），不要直接判成误归因。很多职业技巧正是「某天赋让 X 多了一个效果」（例如让一个外部减伤顺带清某类减益、让驱散多解一种类型）。查到了就写进正文，并把该天赋放进天赋卡；查不到才降级。

## 共享限制作用在谁身上
免疫/大技能常带共享限制（如圣骑士的「自律」、萨满的「力竭」类减益）。按说明确认限制挂在**谁**身上：挂在目标身上的，只影响再给**同一个人**这几个技能，不影响给别人。不要写成「开了 A，B 和 C 都进冷却」。

## 能不能「提前给」
只有目标在机制发生前就确定的（打当前目标、固定点名、首领读条指向某人、团队全体）才能提前交技能。随机点名、背刺、扑人这类，信号是「中了之后」，技能是「中了马上给」，不写「提前给」。

## 常见误用（第一版犯过的）

- 把同一个减伤句子套到每一站：「姿态打底，剑在人在接高压」。减伤只在有具体理由的地方出现。
- 把长冷却位移当躲正面的按钮。走路能躲的不写位移技能，也不写免疫。
- 因为技能名字（「恐惧」「践踏」「烈毒」）推断机制类型。一律以说明文字为准。
- 推荐的天赋没点正文用到的技能。
- 深挖专题的图和标题讲两件事，或画「不减伤 100% / 有减伤 85%」这种天赋说明图。
