# 从证据表挑行

目标：每一行路线、每一张「先学这四招」，都能追溯到证据表里的一条证据，或一个机制事实。

## 证据表怎么读

`evidence.py` 第一节按本职业技能分块（例子取自红玉新生法池·武器战）：

| 字段 | 含义 | 例子 |
|---|---|---|
| 给谁 | 施放目标：自己 / 职责·专精 / 敌方·怪名 | 嘲讽 → 敌方·炎缚毁灭者×24 |
| 伴随 | 施放前后反复出现的敌方机制：场次、次数、倍数（相对随机时刻）、通道、时间差 | 破裂投掷 → 冰霜过载 2/3 场·4/6 次·23.6 倍[身上有] |
| 直接效果 | 驱散、反射、免疫、推断消除 | 冲锋 → 推断消除 风暴之眼×1 |
| 位置 | 哪一段用的 | 首领 1 · 梅莉杜莎·寒妆×4 |

第二节是 5 秒内的连用，例如「嘲讽 → 法术反射 ×18，中位 3.1s」。间隔 ≤2 秒、反复出现的成对技能（如「牺牲祝福 → 圣盾术」）是一套操作，路线里写成一行「A + B」，放在它对应的最危险时刻；第三节是机制事实；第四节是本职业身上的减益怎么结束的。

## 分级

| 级别 | 条件 | 怎么用 |
|---|---|---|
| 必写 | ≥2 场出现；或伴随 ≥5 倍且 ≥3 次；或有直接效果，且技能说明讲得通 | 路线行；最强的进 02 四招和 03 专题 |
| 可写 | 只有一场、倍数一般，但技能说明能解释（例如护盾机制配破盾技能） | 路线行，措辞保守 |
| 线索 | 只出现一次，或技能说明解释不通 | 只放进减益表，或不写 |
| 不写 | 种族技能、饰品、药水、纯爆发技能、坦克专属处理 | — |

伴随只说明时间上接近，不说明因果。必须能用技能说明讲通「为什么」，讲不通就降级。

## 查机制事实

每个要写的机制都要查齐以下几项（证据表第三节，不够时用 `--mechanic`、`--sql`）：

- **施法者**：信号写成「炎缚毁灭者准备读条」，不写「读条开始」。
- **打谁**：当前目标、一名玩家、全团、前方锥形。施放目标大多是坦克的，就是打当前目标，可以用嘲讽改目标。
- **持续与数值**：几秒、每跳多少、结束时有没有爆炸。
- **类型**：伤害系别、能否驱散、是否免控（例如寒冰壁垒「防止控制效果」，就要先打断它）。
- **护盾**：吸收量、护盾在时有什么脉冲、破盾的后果。

## 容易判错的地方
- 「免疫 X」只说明 X 的某次命中被免疫了，不说明技能类型。免控技能可能只是免掉了附带的击退。按技能说明的效果类型重新判断。
- 驱散类型显示「—」是没查到，不是不能驱散。用说明文字或 `--sql` 查 `spell.dispel`。
- 伴随很强、但作用对象对不上的（技能给了小怪，机制落在玩家身上），写的是「对小怪做了什么」，不是「技能解了这个机制」。
- 驱散类技能的最短间隔可能远小于冷却，因为无效驱散不进冷却，不要据此反推冷却。冷却以证据表的冷却列为准，「天赋改」是点了某天赋之后的冷却。
- 不要因为技能名字（「恐惧」「践踏」「烈毒」）推断机制类型，一律以说明文字为准。

## 解释不通时，先查天赋
证据说「技能 X 驱散/免疫/消除了 Y」，而 X 的基础说明做不到时，先查这名玩家点了哪些修改 X 的天赋：天赋树里描述提到 X 的节点，玩家的选点在 `run.combatant` 里。很多职业技巧正是「某天赋让 X 多了一个效果」。查到了就写进正文，并放进天赋卡；查不到才降级。

## 共享限制作用在谁身上
免疫和大技能常带共享限制（例如圣骑士的「自律」）。按说明确认限制挂在谁身上：挂在目标身上的，只影响再给同一个人；不要写成「开了 A，B 和 C 都进冷却」。还要查推荐配置里有没有改写这条限制的天赋。

## 能不能「提前给」
只有目标在机制发生前就确定的，才能提前交技能：打当前目标、固定点名、首领读条指向某人、团队全体。随机点名、扑人这类，信号是「中了之后」，技能是「中了马上给」。

## 不要这样写
- 同一个减伤句子套到每一段。减伤只放在有具体理由的地方。
- 用长冷却位移、免疫去躲走路就能躲的正面技能。
- 03 专题的图和标题讲两件事，或者画「不减伤 100% / 有减伤 85%」这种天赋说明图。
