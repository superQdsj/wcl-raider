## 老 3：加瓦兹特（塞塔里斯神庙 · 兽王猎）

> **一句话流程**：纯单体零合波（中位 3:44），全程自然伤害，按 ~23s 交替循环「**8s 闪电尖塔挡线（镀流）**→**抬血真空**→**诱导全队 AOE + 刷诱导力场电圈**」；15/15 场 0 放电，**兽王猎 15 场本人仅 1 死，唯二真杀/高压点是「诱导后站满 1s 吃诱导力场」与「无减伤长挡整轮镀流 / 误站双线交叉点」**。

1. **【不交】满血（≥90%）单吃「诱导」或单线短触换挡（≤2s / 1–4 跳）「镀流」都不交优胜劣汰与灵龟守护**：诱导与镀流 0 重叠（镀流→诱导间隔 ≥4.82s、中位 8.23s；诱导→镀流 ≥7.80s），满血纯裸吃诱导单发中位 69.6% HP、最高 86.4% HP（129 次 0 死，虽有 22 次落入 14%–19% 但前后抬血窗充裕）；单线短触裸吃 70/70 全 ≥28%（中位剩 71%），减伤必须省给长挡镀流（**若诱导读条结束前血线 <90%，必先交「意气风发」抬满或补「优胜劣汰」**）。
2. **【必交】单人长挡整轮「镀流」（≥2.5s / ≥5 跳，8s 原始伤 ~2.0M–2.7M）进线立刻交「优胜劣汰」，断奶跌破 35% 补「意气风发」**：优胜劣汰持续 8s 刚好盖满一整根柱子（16–17 跳），22 次长挡覆盖优胜劣汰 **0 死 0 残**（中位剩 45%、最低 24%）；无自保长挡即使踩着集结呐喊也会被打至 2% 濒死，或裸吃 7 跳跌至 12% 被迫交龟兜底——无牌时优先与队友短触换挡。
3. **【交互/王牌】「灵龟守护」挡线照常刷新「镀流」防充能且全程 0 伤，关键波次可单人站交叉点 0 伤双挡两根柱子**：灵龟持续 8s 内免疫全部镀流伤害且正常触发每 0.5s 刷新阻止 Boss 充能，甚至可一人扛双线帮全队省牌；但龟壳内无法攻击且实际 CD 124s（15 场仅交 3 次），常规优先用 2 层充能的优胜劣汰，灵龟留作替队扛双线或低血救急，**结束前 0.5s 务必出线**防出龟瞬间吃双跳。
4. **【避坑】「诱导」落地后 <1.0s 内靠无读条移动（必要时交「逃脱 / 猎豹守护」）秒出「诱导力场」，挡线严禁误站双线交叉点裸吃**：诱导力场每 1s 一跳（单跳 ~566K），全队实测 <1.0s 移出 16/16 全 0 伤，站满 1.01s 即吃跳酿成本人唯一死亡；兽王猎全程移动输出本应 0 吃力场，切忌诱导后原地贪站；同时挡线走位勿蹭到相邻柱子射线，无龟壳同毫秒吃双跳会瞬间掉血 25%+。
