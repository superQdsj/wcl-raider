# 老 1：阿斯匹克斯 & 阿德里斯（塞塔里斯神庙 · 惩戒骑）

> **一句话流程**：+23/+24 常规拉入周边小怪合波开打，随「风暴祝福」转火先压死**阿德里斯**摆脱电闪雷鸣，最后留约 40s **狂乱阿斯匹克斯**收尾；Boss 原生全自然伤，**唯一真杀点是「阵风/小怪压血」叠「电闪雷鸣分摊/暴风」**。

1. **【不交】单吃「阵风」「狂风之力」，或满血（>80%）无叠伤单吃 5 人「电闪雷鸣一段」/「暴风」都不交圣佑**：圣佑实际 CD 63s（开怪 13/15 场在 CD，场均仅交 2.2 次），必须省给叠伤轮；狂风之力靠走位防击退入风圈即可。
2. **【必交】进「电闪雷鸣一段」或吃「暴风」前，只要挂着「阵风」、血线 <80% 或少人分摊，立刻交圣佑术**：唯一死亡与 1%–16% 残血全出在此处（哪怕踩着灵魂链接，4 人分摊叠阵风仍会暴毙），交圣佑后中位稳在 67%–74% 血。
3. **【贪输出】「电闪雷鸣一段」落地前 0.5–1s 开圣盾术，一牌三用**：同毫秒清阵风 + 0 伤免一段分摊 + 5s 后原地站撸 0 伤硬吃二段惊雷（20 码秒杀技，省去跑出 20 码的近战断档）；切忌一段落地后再按。
4. **【避坑】纯 Boss 阶段绝不给自己交保护祝福**：Boss 原生自然伤 100% 穿透保护且白吃 30s 自律（锁圣疗）；保护只留给合波带入的**沙怒石拳战士（物理震地）**或**倒刺三叶虫（物理流血）**。

- *实测背书 ①（15 场 +23/+24）*：纯裸吃无叠伤单吃「阵风」89 次全稳 ≥30%、单吃「电闪雷鸣一段」18 次 0 死 0 残；唯一死亡（[r06@1:00.0](https://www.warcraftlogs.com/reports/PqkhAdRaTgcZjMr6#fight=38&view=events&start=17628382&end=17634382)，灵魂链接下 4 人分摊+0.6s 阵风）与最危残血（[r14@0:38.5](https://www.warcraftlogs.com/reports/9kJ4vp1PMxdKzaLm#fight=24&view=events&start=15573364&end=15579364) 阵风叠暴风剩 1%、[r10@0:14.1](https://www.warcraftlogs.com/reports/ByLmahjfWtKzQ8Np#fight=33&view=events&start=25286458&end=25292458) 蜿蜒叠分摊剩 13%）均为叠伤，顶分惩戒 76%（25/33）圣佑全交在此处（0 死 0 残）。
- *实测背书 ②（交互实锤）*：二段惊雷 `1314051` 全队中位 **1.92M（≈150% 惩戒 HP）**，68 波中惩戒 63 次躲避、5 次圣盾站撸 0 伤（如 [r02@1:51.0](https://www.warcraftlogs.com/reports/q6mAK3DwvBV2FtGT#fight=22&view=events&start=6134464&end=6140464)→[1:56.1](https://www.warcraftlogs.com/reports/q6mAK3DwvBV2FtGT#fight=22&view=events&start=6139481&end=6145481)）；圣盾同毫秒清阵风（Δt -2ms，[r04@2:38.3](https://www.warcraftlogs.com/reports/JM6KG3CWqjBZHAyw#fight=1&view=events&start=235344&end=241344)）与暴风沉默（Δt -6ms，[r06@1:45.6](https://www.warcraftlogs.com/reports/PqkhAdRaTgcZjMr6#fight=38&view=events&start=17673945&end=17679945)）；保护穿透 Boss 自然伤 ×11（[r05@1:00.0](https://www.warcraftlogs.com/reports/PFnYKkZxRgDVhqW1#fight=14&view=events&start=10973459&end=10979459)）、仅 0 伤免疫物理震地 ×2（[r05@1:00.4](https://www.warcraftlogs.com/reports/PFnYKkZxRgDVhqW1#fight=14&view=events&start=10973952&end=10979952)）。
