## 重建

仅需 Python 3 标准库。从仓库根目录执行：

```sh
python3 guides/rogue/rebuild.py --output-dir /tmp/rogue-guides
```

默认重建已交付的七份 HTML，输出到指定目录；已存在的文件会被覆盖。
加上 `--include-original` 可同时重建原先的毒牙祭坛页面。
重建器替换技能图标、天赋图标及天赋导入字符串，并校验图片编码和未替换的占位符。
修改攻略时以表中主源稿为准，再运行统一重建器；分片文件仅作为历史材料保留。

原 `build.py`、`enc.py`、`dec.py` 和 `edit1.py` 是历史快照，部分含绝对临时路径或写死的
专精、英雄天赋节点；不要直接视为通用工具运行。制作新的职业手册见 `../tools/README.md`。
统一重建入口不依赖这些临时路径，不重新推导或修改已保存的天赋配置。
