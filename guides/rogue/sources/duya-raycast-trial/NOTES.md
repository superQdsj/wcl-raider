# 毒牙祭坛 · 潜行者 — Raycast 风格试验版（非正式）

2026-11-15 的风格试验，**不是正式攻略**，不发布到网站（成品叫 `trial.html`，放在 `sources/` 下面，`scripts/build_site.py` 只收 `guides/<职业>/` 顶层的 HTML）。
正式版仍是 `../../2026-11-15-毒牙祭坛-潜行者.html`（源码 `../duya-v2/`）。

重建：`python3 build.py` → `trial.html`。图标和天赋字符串直接读 `../duya-v2/` 的 `icons.json`、`tstring.json`；
`timeline.py` 是本目录自带的变体（多了 `.gl` 网格线和 `.pin` 图标包裹），和 `../../tools/timeline.py` 不通用。

## 试验了什么

**内容**：一条路线主线，每条知识只说一次。正式版有 7 个板块（时间轴、先学四招、祖尔加专题、路线、工具箱、减益表、天赋），
同一条知识（例如"三重喷吐交斗篷"）在里面出现 6 次。试验版只留 3 个板块：

- 时间轴：金色 = 必做的斗篷，红色 = 闪避接切骨者，灰色 = 顺手交的斗篷。
- 按路线逐段：「先学四招」变成路线里高亮的"必做"行；祖尔加专题并进祖尔加段，改成"一轮仪式"的步骤；工具箱缩成标题区的四个核心技能；减益表删掉。
- 天赋：只列四个不要动的防御天赋，可换的写一句。

**观感**：Raycast 的语言，全页只用"启动器窗口"一种组件——搜索栏（面包屑 + 标题）→ 列表（右侧键帽 = 要按的技能，选中行 = 必做）→ 底部操作栏（这段交几次斗篷、下一段）。
窗口是毛玻璃（半透明 + blur + saturate + 顶边高光），每个窗口后面放彩色光晕，玻璃才看得出来。去掉所有分类标签，颜色只表示一件事。

## 过程中的结论

- 原 Raycast 样本凌乱的原因不是颜色多，而是 Raycast 的语言没有贯彻：只有路线用了启动器窗口，其余换成卡片、表格、柱状图、宫格等六七种版式，标签颜色也没有固定含义。
- "克制、灰阶、细线、单一强调色"是 Linear 的精髓，不是 Raycast 的——中间做过一版这样的，被指出像 Linear 版。Raycast 的精髓是"拿产品界面当插画"：启动器窗口、键帽、光泽图标、玻璃透出背后的光。
- 内容去重和风格无关，任何风格都可以沿用。
