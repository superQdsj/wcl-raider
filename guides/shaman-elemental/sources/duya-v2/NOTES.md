## 技能基础窗口与关键结论依据

### 技能基础窗口来源（`evidence/spells.md` + Wowhead 天赋说明）
- 星界转移：基础 2 分钟，位面旅行者 −30 秒 → 90 秒；−40%，12 秒。实测最短间隔 90.8 秒。
- 土元素：3 分钟，30 秒；始源羁绊（1279819）改为不嘲讽、最大生命值 +15%。
- 幽魂之狼 + 雷霆之爪（378075）：变狼移除诱捕效果，每 20 秒一次。dispels 里 `雷霆之爪(378076) → 麻痹射击(1294569)` 在 r1/r4/r5 出现，r2 用幽魂步清掉。
- 风剪：12 秒；风幕（355630）打断后法术伤害 −15%，12 秒。
- 清毒图腾：2 分钟，6 秒（图腾集中 +3 秒），每 1.5 秒清一人中毒。
- 自然守护者：35% 血线以下回 40%，45 秒一次；元素防护：魔法伤害 −8%。
- 读条时长（raw enemy begincast→cast）：鲜血献祭 3 秒、剧毒涌动 2 秒、同步毒液 2 秒、濒死喘息 5 秒、毒牙仪式 5 秒、切骨者 5 秒。

### 关键结论（窗口内外对比）
- **鲜血献祭 → 星界转移**：compare.md 星界窗口 15 次、预开 15/15，r1–r5 都有；有伤害 31.5 万（25%）→ 18.9 万（15%）。开场 r1/r2/r4 2–3 次交献祭，r3 只 1 次，r5 第一次交恶臭喷吐 → 段尾写 1–3 次。
- **嘶嘶食腐 → 星界转移**：r1/r2/r3 两次星界都在拉维腐肉喷发叠层时（相对开打 +32~+83 秒与 +199~+207 秒；腐肉喷发 +29/+82/+143/+205），狼吞虎咽 9 次全在星界窗口内（接腐肉块）。r4/r5 改交三重喷吐（见删掉的打法）。腐肉喷发开启偏移中位 +2.0 秒 → 正文写"开始叠层就开"。
- **三重喷吐 → 土元素**：r2/r3/r4/r5 拉维战土元素都在被毒球砸中后召（uses 前减益=三重喷吐），正文写"被点到就召"。
- **振响 → 星界转移**：r1/r2/r3/r5，预开 5/6；24.3 万（19%）→ 14.6 万（12%）。
- **感染 → 星界转移**：r1–r5 都有，预开 0/5、中位 +1.2 秒 → 正文写"上身后马上开"。
- **剧毒涌动 → 星界转移**：r1/r2/r3 两拨都交，r4 第一拨晚开 10 秒，r5 感染后 82 秒冷却未转好、第一拨改交土元素（4/5 场至少一拨）；每拨由同一个神选者约隔 25 秒读两轮涌动，星界只盖第一轮；每跳 14.4 万 → 8.2 万（对比条，五场都有两组数据，均为跳伤单一口径）。预开 3/8、中位 +1.3 秒 → 写"风暴一起就开"。
- **土元素 → 神选者**：r1/r3/r4/r5 交在神选者剧毒涌动（r1/r3 第二拨、r4/r5 第一拨，多为星界没盖到的那轮）。
- **切骨者 → 星界转移**：r1/r2/r5 拦光束后（仪式毒液在身），预开 5/5、中位 −1.2 秒。r1 raw 时序：毒牙仪式读条 0 → 光束 +5（8 秒）→ 切骨者读条 +32 → 命中 +37 → 流血每秒移除一层仪式毒液 → +44 清空；第二把飞斧读条 +48；仪式每 65 秒，萨满隔轮拦（约 130 秒）。切骨者直击开星界仍 60.1 万（48%）→ 硬限制"接斧前抬满血"。r3/r4 没拦光束，不影响结论。
- **麻痹射击 → 幽魂之狼**：debuffs.md 麻痹射击消失时幽魂之狼 r1/r4/r5，r2 幽魂步；dispels 雷霆之爪 7 次。
- **进化 → 群体毒伤 → 清毒图腾**（Council Opus 指出）：#5 那波有一只高阶进化者完成进化(1307602，带 25 万盾、免控)后读群体毒伤(1307567，3.5 秒)，r1 12:18/r2 11:50/r4 12:34 读完，全队挂毒伤(1307571，驱散：中毒)；五场的第一次清毒图腾都插在这一刻。第二次清毒图腾在盘蛇后那波进化者。淬毒之刃没有中毒标记，正文写清毒图腾驱不了。
- **妖术 → 原始毒蛇**：r1–r5 开怪第一个技能都是妖术原始毒蛇#1。
- **净化灵魂 → 被诅咒的骨头**：r1–r5 都在第二波尾和进化者段尾驱散友方物件"被诅咒的骨头"身上的 被诅咒(1309980)。驱散后放出 抚慰的阿曼尼精魂（五场 names.json 都有），其技能 远古守卫的援助(1310018)：敌人受到伤害 +1%，30 秒，最多 5 层（Council Sol 指出）。
- 打断（interrupts.md）：毒伤 71、刺耳嘶鸣 54、群体毒伤 16、剧毒萎缩 5（r1/r2/r5；全队 33）→ 四个必断读条。恶臭喷吐全队 0 次打断 → 正文"风剪留给刺耳嘶鸣"。
- 贪婪践踏 59% 血、同步毒液、不稳定的图腾、恶臭喷吐：没有任何场次对应开减伤（或不足 3 场），正文只给站位/处理建议。
