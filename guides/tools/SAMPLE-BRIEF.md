# 交接：做一本「样板攻略」+ 样板规范

## 目标

把三份攻略的长处合成**一本样板**，再写一份**样板规范**，以后所有职业的攻略照着模仿。
目的不是逐页修错（那一批已在 `0c88460` 提交），也不是改动已发布的其他攻略。

A 和 C 是**同一副本、同一批数据**，只是组织方式和视觉不同，所以样板拿**毒牙祭坛·盗贼**来做，比较的只是写法。

## 三方评审（Opus / Neon / Sol）的结论

总分：A 7 / 7.2 / 7，B 4.5 / 8.2 / 6，C 8 / 8 / 8。

**样板要从各版拿走的长处**（三家意见基本一致）：

- **C 的内容组织**：一条路线讲到底，每条知识只说一次。A 里「三重喷吐交斗篷」一类的知识重复了 6 次，C 去掉了这些重复。必做行高亮，颜色只表示一件事（金色 = 必做）。每段开头一句「节奏」，段尾写「这段交几次 / 下一段」。手机上 A 约 10,500px 长，C 约 7,000px。
- **B 的查找方式**：顶部速记区（三四个核心技能，加一条职业硬限制，例如自律），「全本必断读条」清单（点击跳到对应战斗），阶段导航（01–05）。这些适合开打前看 5 分钟、打本时瞄第二屏。B 的筛选和高亮交互可以不要。
- **A 的工程和证据**：sources/ 能重建，NOTES.md 写明每条结论的依据，用共享的 `guides/tools/timeline.py` 生成单轨时间轴，结尾放天赋字符串（编码后解码对照），图标外链到 `guides/icons/`。

**各版要避开的问题：**

- **A**：
  - 七个板块重复。
  - 「先学四招 / 工具箱 / 减益表」三块和路线内容重叠。
  - 没有页内跳转。
- **B**：
  - 营销腔（已修）。
  - 正文里写样本数、写只有一场出现过的打法（已删）。
- **C**：
  - 删减表格时丢了信息，例如「感染爆幼体马上打」「消失也能解麻痹」。删任何板块前，要先把只在那里出现过的信息挪进路线。
  - 灰色小字压在毛玻璃上，对比度太低。
  - `timeline.py` 是本地分叉的一份。
  - 底栏的统计次数有误（已修）。
- **共同问题**：A 和 C 都依赖 Google Fonts，国服可能加载不到。B 用系统字体。

## 动手前先问用户的两件事

1. **视觉**：用 A 的「毒林夜色」，还是 C 的 Raycast？我倾向用 A，理由有两条。记忆里有用户的决定：「Raycast 只作试验」。评审里也有两家认为 Raycast 不适合全职业推广。这件事由用户拍板。
2. **样板放哪里**：建议新建 `guides/rogue/sources/duya-sample/`，生成一份新页面，暂时不替换已发布的正式版。用户看过以后，再决定要不要替换 A。

## 要交付的东西

1. **样板页**：`duya-sample/` 下放源码和 `build.py`，生成样板 HTML。内容和数据沿用 A 已修正的版本。斗篷约 5 秒、喷发前斗篷要已转好这些修正都已在 A 里。结构按上面「长处」那一节合成。
2. **样板规范**：可以写进 `guides/tools/README.md` 的「写作」一节，或者另建文件。内容是：每个板块的作用和顺序、硬规则、新职业怎么套用（比如怎么选核心技能、怎么判断有没有必断职责）。规范写完后，`tools/README.md` 里那条「试行」要删掉或改写，标准只能有一份。
3. **评审**：用 `council` skill（Opus / Neon / Sol 6.2，high）。问题是「这本样板和这份规范，能不能当所有职业的模板」，打分目标 ≥ 9。

## 规则（来自 `guides/tools/README.md` 和仓库 `CLAUDE.md`）

- **写攻略，不写统计报告。** 写看到什么、按什么、为什么。正文不写「5/5 人」「五场」「共 N 次」；数字只在能说明「为什么这样按」时用一个，比如「少吃三成」「伤害砍半」。
- **样本**：五个人里只有一两个人这样做，就删掉；多数人一致才写。
- **交付**：只交付 HTML，不截图，不管手机宽度。
- **读取限制**：成品 HTML 和 `dist/` 不要整份读取，用 grep 定位后只读相关行；不要读 `icons.json`。
- 源码目录按 `sources/<副本拼音>-v2/` 的惯例命名；样板可以叫 `duya-sample/`。

## 不做

- 不改其他已发布的攻略（30 多本）。
- 不顺手修别的东西。看到问题就记下来，在回复里列出。
- 不改全站字体。如果样板决定不用 Google Fonts，只在样板里改，并写进规范。
