# 老 2：米利克萨（塞塔里斯神庙 · 惩戒骑）

> **一句话流程**：纯 Boss 战不合波外部小怪（中位 3:57），围绕约 103s 周期交替打 **P1 地面期**（缠绕蛇群→雷霆喷吐→约 12s 后毒蛇风暴→钻地）与 **P2 钻地清怪期**（中位 50s 全程「钻地之震」+「剧毒蝰蛇/风暴飞蛇」）；除蛇群与小怪平砍外全为自然伤，**惩戒 15 场本人 0 死，真威胁集中在 P1「雷霆喷吐」4 秒高频压血，以及 P2「钻地之震」叠踩雷池/漏断毒液/OT 平砍**。

1. **【不交】「缠绕的蛇群」、常规有抬血的「钻地之震」，以及圣佑在 CD 时满血且有持续抬血的「毒蛇风暴」都不交大牌**：蛇群中位 0.44s 即被顺劈/控破，纯裸吃仅 195K（18%HP，20 次最低 69%）；「钻地之震」每秒仅 ~100K，不叠伤且有抬血时无需交减伤（若持续断奶血线跌破 30% 再补自疗）；圣佑实际 CD 63s（开怪 8/15 场在 CD，场均仅交 2.0 次），圣盾与保护 15 场实测均为 0 次主动交出，留作极端急救或老 2 后合波。
2. **【必交】每轮 P1 圣佑术按「被点雷霆喷吐优先，未点再交毒蛇风暴」分配；雷霆前 2–3 跳断奶跌破 50% 备圣疗术兜底**：每轮 P1 两招仅隔约 12s，圣佑只能保其一——「雷霆喷吐」4 秒 5 跳纯裸吃中位 1.81M（164%HP，+24 可达 2.14M），是全场唯一逼出自身圣疗的 2%–7% 残血来源（边移动躲开脚下雷击；单口永恒之火或单开圣佑在断奶时仍会跌破 10%，需备圣疗兜底），交完后约 12s 后的「毒蛇风暴」在满血且有持续抬血时裸吃可稳（CD 裸吃 10/10 全 ≥26%，完整 9 跳窗内抬血 1.30M–1.91M）；未被点「雷霆喷吐」时再把圣佑交给「毒蛇风暴」（首跳击退中位 618K + 8s DoT 总伤 1.76M，交圣佑后中位稳在 47%、最低 31%）。
3. **【交互】P2 所有打断与控制全部死盯「剧毒蝰蛇」的「毒素喷吐」，P1 队友被「缠绕的蛇群」控住可用盲目之光顺手秒救**：「责难」（场均 2.6 次，14/15 场，38/39 目标为剧毒蝰蛇）、「制裁之锤」（8/8）与「盲目之光」（8/11）全部用来压制「毒素喷吐」（全队将 278 次读条压到仅放出 8 次，漏断单发+8s 中毒可伤 718K，也是全场唯一可由「清毒术」补驱的中毒）；「风暴飞蛇」的「风暴触媒」不强断，躲开 4 码落点与「萦绕风暴」雷池即可；P1 顺劈或盲目之光（3/11）可瞬间双解缠绕队友。
4. **【避坑】严禁给自己交保护祝福，也别对「毒蛇风暴」交清毒术；钻地阶段躲路径并防剧毒蝰蛇起手 OT**：Boss 核心技能（毒蛇风暴/雷霆喷吐/钻地之震/萦绕风暴/钻地）**100% 为自然伤**，保护完全穿透且白挂 30s 自律锁圣疗（15 场 0 次使用）；「毒蛇风暴」`1293048` 属不可驱散自然 DoT（全队 15 场 0 驱）；「钻地」`264206` 路径撞击中位 1.56M（≈142%HP）+ 晕 4s，惩戒 30/30 全躲；P2 孵化出怪时切忌先手抢仇恨吃剧毒蝰蛇平砍。

- *实测背书 ②（交互与机制实锤）*：「缠绕的蛇群」20 次裸吃最低 69%（[r13@3:37.1](https://www.warcraftlogs.com/reports/vwJc2Hd6jQChxp71#fight=1&view=events&start=996285&end=1002285)），盲目之光实测 +0.02s 同时解救 2 名被缠队友（[r14@1:57.0](https://www.warcraftlogs.com/reports/9kJ4vp1PMxdKzaLm#fight=24&view=events&start=16255483&end=16261483)）；P2 剧毒蝰蛇「毒素喷吐」`267027` 共读条 278 次仅放出 8 次（责难实测如 [r01@1:03.3](https://www.warcraftlogs.com/reports/BLmWKxty6VMNvhR4#fight=1&view=events&start=9710085&end=9716085)），全队 4/4 次有效驱散全为此中毒效果（均由治疗完成，惩戒 3 次清毒均未抢到有效驱散；「毒蛇风暴」`1293048` 0 次驱散）；「钻地」`264206` 惩戒 30/30 全躲（全队命中中位 1.56M，圣盾/保护全 15 场 0 次主动施放）。
