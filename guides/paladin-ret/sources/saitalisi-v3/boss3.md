# 老 3：加瓦兹特（塞塔里斯神庙 · 惩戒骑）

> **一句话流程**：纯单体零合波（中位 3:40），全程自然伤害，按 ~23s 交替循环「**8s 闪电尖塔挡线（镀流）**→**~6s 抬血真空**→**诱导全队 AOE + 刷诱导力场电圈**」；14/15 场 0 放电，**唯二真杀/高压点是「诱导后慢出诱导力场」与「无减伤长挡整轮镀流」**。

1. **【不交】满血（≥90%）单吃「诱导」或短触换挡（≤2s / 1–4 跳）「镀流」不交圣佑术**：圣佑实际 CD 63s（开怪 4/15 在 CD，场均 2.73 次），必须留给长挡镀流；诱导与镀流 0 重叠（间隔 ≥4.83s、中位 6.07s），满血裸吃诱导单发最高打 86% HP 但 0 死且前后有 5–8s 抬血窗（**读条结束前 <90% 血或刚吃漏线「放电」必交圣佑/抬满**）。
2. **【必交】单人长挡整轮「镀流」（≥2.5s / ≥5 跳，8s 原始伤 ~2.0M–2.5M）进线立刻交圣佑术**：8s 圣佑刚好盖满一整根柱子（32 次长挡交圣佑 0 死 0 残，中位剩 50%、最低 29%）；纯裸吃长挡剩血中位跌至 32% 并包揽全部 4 次镀流 <20% 险情与全部 3 次自交圣疗，圣佑 CD 时优先换挡或备「圣疗术」兜底。
3. **【交互】「圣盾术 + 牺牲祝福」一键双线 0 伤王牌，牺牲必须抢在开圣盾前/同帧早挂**：开圣盾挡线照常刷新「镀流」防充能却 **0 伤害**（8/9 次圣盾用于挡线），联动给另一条线队友挂牺牲可白嫖 30% 减伤且圣盾内转移伤全 0（6/9 次这么打）；但牺牲持续 12s 长于圣盾 8s，3/6 次连招晚挂（哪怕仅慢 0.8s）出无敌后尾段仍会撞上「诱导」吃重伤（最高 204K），常规牺牲（28/28 全给挡线队友）晚挂同样会在诱导同毫秒压至 20% 断线阈值，故务必抢早挂出且诱导前保满血。
4. **【避坑】「诱导」落地 <0.85s 内必须秒出「诱导力场」，且全程绝不交「保护祝福」**：诱导力场每 1s 一跳（241K–579K），实测 <0.85s 移出全 0 伤，站满 ≥1.0s 吃跳即酿全场唯一死亡；Boss 全自然伤，保护 100% 穿透（0/15 场使用）且白吃 30s 自律锁圣疗——抢救双大牌务必**先圣疗再圣盾**（圣光决断下自律不锁圣盾）。
