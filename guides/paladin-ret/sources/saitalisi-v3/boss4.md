# 老 4：塞塔里斯的化身（塞塔里斯神庙 · 惩戒骑）

> **一句话流程**：+23/+24 常规打两轮循环（中位 3:43）——先清**堕落的守护者**（击杀时出 20 码躲「不稳定腐化」死爆，并由 3 人各领 1 层 15s「腐化」）、转火**精华污染者**解除「污染之秽」禁疗，同时断**扭曲的妖术师**「烈焰震击」并躲开治疗脚下「妖术淤泥」；转阶段控杀锁治疗的**无信折磨者**并帮奶化身。**全场真杀点只有叠吃 2–3 层「腐化」，以及「邪恶冲锋」交错牌导致「腐化」轮无自保**。

1. **【不交】满血（>90%）且治疗空窗能单抬时，单点「邪恶冲锋」尽量省下圣佑术**：圣佑 63s CD 而冲锋交圣佑后 7–34s（冲锋后 11–40s）就会进「腐化」，提前交圣佑保冲锋 100% 会让下轮腐化陷入圣佑空窗；单点冲锋裸吃 0 死，仅当你不负责下轮吃腐化、手握圣盾兜底，或半途跌破 40% 且治疗断奶时才交圣佑。
2. **【必交】领 15s「腐化」必覆自保（圣佑或圣盾二选一）并防范后半段 7s 裸露，严禁多领叠至 2–3 层**：单层腐化持续 15 跳（实际+吸收总伤中位 3.09M，裸吃/低减伤 3.3M–3.61M），无自保仅靠外减也会跌至 5% 残血；圣佑/圣盾均只覆 8s、无法覆满 15s，**后半段 7s 裸露期需补自疗或接力团减防跌破 10%**；若误叠 2–3 层，单跳伤害翻倍至 533K–887K/s，踩着集结呐喊也会在 2–3s 内暴毙。
3. **【交互】圣盾术在「腐化」中一牌两用（0 伤抗 8 跳 + 顺手给同吃腐化队友甩牺牲祝福），但注意不清除 Debuff**：圣盾不驱散「腐化」本身（8s 结束后剩余跳数继续掉血），且牺牲持续 12s 长于无敌 8s——开无敌后尽早给队友套牺牲可 0 伤帮扛，切忌**未开无敌且自己身背腐化时裸交牺牲**，反噬叠跳极易把血线打穿至 16%–20%。
4. **【交互】用「圣疗术」直接奶塞塔里斯的化身加速收尾，控断分工盯死两类小怪**：奶化身不触发惩戒骑自身自律；开怪 15.3s「污染之秽」落地前趁无禁疗先给化身甩第一口圣疗，3 分钟实际 CD 转好后末期可奶第二口；**责难**全盯扭曲的妖术师「烈焰震击」，**制裁之锤**控锁治疗的无信折磨者（潜藏妖术 100% 点治疗，专注控断即可）。
5. **【避坑】绝不给自己交保护祝福，保护只留给被无信折磨者锁定围殴的治疗**：本场核心威胁技（腐化、邪恶冲锋、不稳定腐化）均为暗影伤，保护 100% 穿透且白吃 30s 自律；转阶段给被大量无信折磨者锁定的治疗套保护，可 0 伤免疫物理平砍、防叠 5%/层减疗。
