# 全本小怪（塞塔里斯神庙 · 惩戒骑）

> **一句话流程**：+23/+24 全本小怪中位总时长 13:54（常合为 ~5 大波推进），高压点集中在**老 1 前「震地+物理流血」、老 1–2 间「流血+细胞毒素」双 DoT 叠伤、老 2 后「暴怒云气·释放电荷」**与**老 3 后「蚀骨践踏」**；惩戒骑靠 **63s 圣佑 + 保护/圣盾分工 + 清毒/正义保护牺牲双解毒 + 场均 16.7 次责难** 即可将 15 场本人真死压至仅 3 次。

1. **【不交】满血（>80%）单吃无叠伤的「蜿蜒打击」「箭雨」「萦绕风暴」，以及满血无叠伤单点「细胞毒素」「锯齿冲锋」都不交圣佑与大牌**：满血（>80%）单点细胞毒素秒交清毒术即可（无叠伤纯裸吃 0 次 <25% 血，最低 91%→28%），无叠伤锯齿冲锋纯裸吃 62 次仅 2 次 <20%（最低 16%，另有 2 次恰 20%）；圣佑实际 CD 63s（小怪场均 7.27 次，复仇之盾全本 0 次主动施放），必须留给爆发 AOE 与叠伤波。
2. **【必交】吃「沙怒石拳战士·震地」「暴怒云气·释放电荷」、有圣佑优先覆「宝珠守望者·蚀骨践踏」（低血 <70% 或搬球断奶波次必交），或「锯齿冲锋」叠「细胞毒素/震地/闪电箭」时，立刻交圣佑术**：裸吃震地与释放电荷单发净扣 65%–97% 血量（极限逼近 100%；释放电荷纯裸吃 73 次中 16 次 <20%、最危 100%→3%，交圣佑中位稳 78%）；锯齿叠伤连招哪怕有集结呐喊仍会压至 2% 血（靠随后灵魂链接救回）；蚀骨践踏为 10s 不可驱散高伤 DoT（10 跳合 2.28M），且圣佑仅覆前 8s，尾 2 跳若治疗搬球断奶需自接荣耀圣令/圣疗或圣盾。
3. **【免疫/清除】保护祝福专吃物理「震地」与清「锯齿冲锋」流血；圣盾术留给自然伤爆发、多伤叠杀与「蚀骨践踏」断奶尾跳**：保护 10s 内可 0 伤免疫震地与锯齿冲锋，或同毫秒清掉已挂身的锯齿流血（中位 2.4s 提前清）；圣盾术全能免疫释放电荷/萦绕风暴/火花步/蚀骨践踏，并可同毫秒清掉蚀骨践踏（不可驱散）与双 DoT 叠伤。
4. **【交互】「清毒术」秒解自身与队友「细胞毒素」，清毒 CD 或双点毒波次用「牺牲祝福（正义保护天赋 469321）」同步驱毒+减伤；老 3 后搬球走廊把「自由祝福」交搬球坦克或自身**：正义保护天赋下，牺牲祝福对队友施放可 0ms 瞬驱细胞毒素并防再中毒（34 次牺牲中 14 次直接驱毒，全给敏锐贼/恢复萨/武器战，多次用于清毒 8s CD 真空期）；搬球区自由祝福 100% 免疫「极化力场」35% 减速（12/12），优先保搬球坦克快速通过。
5. **【控断】「责难」死盯四条必断链，「制裁之锤」与「盲目之光」专停钢条/引导与抢球怪**：责难优先断 **唤雷者/风暴能手「闪电箭」**（漏断单发 751K）、**育巢者「毒箭」**（单发 735K 且穿保护）、**无信征服者「扰乱心智」**（5s 迷惑）与 **扭曲的妖术师「烈焰震击」**；制裁之锤主盯唤雷者、**神庙干扰者**（防搬球区干扰）及**流沙猎手「箭雨」**，盲目之光作群断专压箭雨与蛇虫齐发波；血精灵还可用奥术洪流进攻驱散暴怒云气「积攒电荷」。
6. **【避坑】绝不对自然伤给自己交保护、绝不对「蚀骨践踏」浪费清毒、残血（<55%）别靠清毒硬扛连发毒素，并远离「不羁的火花」与防抢仇恨**：保护 100% 穿透蜿蜒打击/细胞毒素/毒箭且白吃 30s 自律锁圣疗（3 次 <20% 残血恰逢自律锁圣疗）；蚀骨践踏无中毒标签清毒无效；全本惩戒骑仅有的 3 次真死分别死于 41% 血刚自清毒 0.5s 后再吃第二发细胞毒素 460K 首击（圣佑/圣盾全就绪）、箭雨后吃三叶虫主母 1.00M 近战平砍，以及走廊硬吃「不羁的火花」934K 秒杀。
