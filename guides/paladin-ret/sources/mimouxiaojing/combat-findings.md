# 惩戒骑 · 密谋小径 +22：战斗应对还原

本轮加入圣疗术，继续排除责难。不制作或注册手册。

使用方法：先看敌方机制说明，再查玩家技能是否能处理该机制，最后用施法、增益、减益、伤害和治疗的先后顺序确认实际效果。日志能确认行为与结果，不能直接证明玩家当时的意图。下述“理解”是建立在这些事件上的解释。

## 来源与补查

- r1：[天下第一骑，fight 1](https://www.warcraftlogs.com/reports/tAYXZrKG4HcbVpkf#fight=1)。
- r2：[Tracer，fight 33](https://www.warcraftlogs.com/reports/r1ChwFYjNM7XkWp9#fight=33)。
- r3：[Âra，fight 42](https://www.warcraftlogs.com/reports/BjYy6LNJAwnDbrK8#fight=42)。

均为 +22 限时记录。所有时间均为战斗内相对时间。

本轮新增10个限定时间窗口，WCL `All / Friendlies / includeResources:true`，按相关玩家的 source.name 或 target.name 过滤。每个窗口 JSON 保存报告链接、起止时间、过滤表达式、截断状态和原始事件；均未截断。对应 TXT 是筛出的关键事件，完整上下文以 JSON 为准。敌方读条用此前的 `raw/runN_enemy.json` 核对。文件在 [evidence/scenarios/](evidence/scenarios/)。

双方技能说明来自项目工具获取的 Wowhead tooltip，保存在 `evidence/spells.md`、`evidence/supplemental/utility-spells.txt` 和 `evidence/scenarios/spells.txt`。说明用于理解伤害类型、持续方式和技能能力；不把基础伤害值当成22层实战伤害，也不由跨玩家均值反推减伤比例。

## 1. 圣盾术：中吸取生命后，直接结束自己身上的效果

机制：[吸取生命 1297682](https://www.wowhead.com/spell=1297682)由腐化的术士施放，持续7秒、每秒吸取目标生命并转移给施法者。[圣盾术 642](https://www.wowhead.com/spell=642)免疫伤害和有害效果。

还原 r3：

- 13:05.522，术士开始读吸取生命；13:07.521 施放完成。
- 13:07.522，Âra 获得吸取生命减益；13:07.750 吃到一跳约30.1万伤害。
- 13:08.083，圣盾增益出现，吸取生命减益在同一毫秒移除。
- 后续补查窗口内没有继续受到吸取生命伤害，13:10.388 的剥离攻击也记录为免疫。

同样的“圣盾开出、吸取生命立即移除”也出现在 r2 13:05.2 和 r1 21:27.6。

理解：这是针对持续吸血效果的解除手段，收益包括停止后续对自己的吸血伤害；并非只是在低血量时临时减伤。日志没有证明对其他目标、其他次施法也会产生相同后续，故不扩大为通用打断结论。

证据：`bubble-drain.json/.txt`。

## 2. 保护祝福：预先免疫绝命凶径，可给自己也可给队友

机制：[绝命凶径 474763](https://www.wowhead.com/spell=474763)先瞄准，之后向视线内玩家射击，造成物理伤害并附加流血。[保护祝福 1022](https://www.wowhead.com/spell=1022)使目标免疫物理攻击及相应有害效果。

还原 r2：9:16.089 出现瞄准减益，9:18.132 Tracer 给自己保护；9:21.724 射击落下，伤害为0，hitType=10（免疫）。

还原 r3：8:43.045 Doxorsw 被瞄准，8:44.460 Âra 给他保护；8:48.831 Doxorsw 吃到的射击同样为0，明确标记免疫。

理解：保护能作为这一轮物理射击的针对性应对，也能支援队友。两场都有瞄准、增益和免疫结果，已经超出“恰好在附近按了保护”的线索。坐标、视线和输出收益尚未核对，因此不写成固定站位或无条件站桩建议。

另一个用途：r2 19:50.902 中剥离，持续流血把血量压低；19:52.952 保护增益出现，同刻剥离移除。剥离说明明确为物理流血，与保护的能力相符。但这次已经接近3秒持续时间的末尾，不能据此宣传省掉了完整一轮流血；更早使用的收益需要另找样本。

证据：`bop-boss2`、`bop-ally-boss2`、`bop-bleed` 的 JSON/TXT。

## 3. 清毒术：清掉的是叠层中毒，不是附近同时消失的流血

机制：[断心药膏 1216590](https://www.wowhead.com/spell=1216590)为可叠层中毒，持续造成自然伤害，并降低最大生命值。[清毒术 213644](https://www.wowhead.com/spell=213644)移除中毒和疾病。

还原 r1：0:50.1 队友 Vsvfasknmcxz 中毒，0:53.3 已叠至4层；0:55.0 天下第一骑对其清毒，WCL 有明确“清毒术驱散断心药膏”的成功事件，目标中毒同刻移除。该玩家本场还有多次相同的成功驱散。

理解：在街头扒手参与的战斗中，惩戒可以主动处理队友的叠层毒，解除持续伤害及降低最大生命值的负担。证据包 uses.md 同时出现的本人“妙手空空”消失不代表清毒能解流血：那是不同目标的事件，不能合并为因果。

证据：`supplemental/cleanse-dispels.txt`、`cleanse-target-debuffs.txt`。

## 4. 圣佑术与复仇之盾：覆盖持续伤害和即将重叠的爆发

玩家技能说明：[圣佑术 403876](https://www.wowhead.com/spell=403876)提供8秒减伤，tooltip 包含施放复仇之盾的天赋分支；[复仇之盾 184662](https://www.wowhead.com/spell=184662)提供吸收盾。三场首个圣佑施法均同时获得这两个增益，没有独立复仇之盾施法，符合本样本的联动行为。这里按观察到的联动规划应对，不安排两个独立按键。

三号首领场景 r1：

- 地狱火碾压说明为初始火焰伤害加8秒持续伤害；玩家此时仍在吃碾压跳伤。
- 16:35.439 首领开始读魔化狂怒；该技能说明包含全队瞬间混乱伤害。
- 16:38.369/370，玩家获得复仇之盾、圣佑两个增益。
- 16:38.690，碾压的一跳被盾完整吸收，hitType=1，不是免疫。
- 16:39.450，魔化狂怒落下，盾吸收约25.2万，其余约23.9万扣血，随后盾耗尽。

理解：这是在旧的持续伤害尚未结束、新的群体爆发即将到来时开防御，覆盖重叠压力。不能只因为碾压一跳为0，就写成免疫碾压。

一号首领场景 r3：混沌爆裂说明中，首领会暂时昏迷并受到额外伤害，同时每秒对全队造成伤害。6:11.938 Âra 开圣佑并获得盾，6:12.347 的混沌爆裂被完整吸收，之后盾耗尽但圣佑仍持续到6:19.947。理解为利用防御撑过机制持续群伤，不能由此断言盾能覆盖整个阶段。

证据：`divine-protection-boss3`、`divine-protection-boss1` 的 JSON/TXT；敌方读条在 `raw/run1_enemy.json`。

## 5. 牺牲祝福配圣盾：保护队友，同时免疫自己承担的转移伤害

机制：[牺牲祝福 6940](https://www.wowhead.com/spell=6940)把队友受到的部分伤害转移给施法者。尾王灼热邪焰每秒辐射火焰伤害，自己与队友会同时承压。

还原 r1 尾王：26:56.984 天下第一骑给等我买杯奶茶牺牲；26:57、26:58 均记录到自己承受约2.86万牺牲转移伤害。26:58.973 开出圣盾后，队友身上牺牲仍在，自身灼热邪焰标记免疫，牺牲转移事件实际扣血变成0。27:06.996 圣盾结束，27:07.122 再次承受约2.73万牺牲转移伤害；牺牲到27:08.984 才结束。

理解：这是有前后效果证据的组合——支援队友的同时，用圣盾覆盖自身群伤和转移伤害。但牺牲持续比圣盾更久，窗口外仍有转移伤害，不能把整段牺牲都当成无代价。日志确认这名玩家先牺牲后圣盾，不把这个顺序硬写成唯一正确顺序。

证据：`bubble-sacrifice-lastboss.json/.txt`。

## 6. 圣疗术：补足血量，持续伤害仍需另行处理

技能说明：[圣疗术 633](https://www.wowhead.com/spell=633)治疗量相当于施法者最大生命值，并涉及目标自律限制。实际有效治疗以 heal.amount 为准，过量治疗单列，不能把 tooltip 的总量当成全部有效治疗。

场景A，救队友：r2 一号首领，Swordish 同时受到邪能风暴、混沌弹幕和被带入首领战的小怪妙手空空流血。5:20.784 弹幕后血量跌低；5:22.310 Tracer 对其圣疗，有效治疗827607，回到1053360满血。5:22.667 仍有流血扣血。理解：惩戒用大额瞬发治疗拉起遭受多源伤害的队友，持续效果没有因此消失；不是固定“每次弹幕必交圣疗”。

场景B，三号高层闪电自救：r3 魔能闪电说明为每秒跳伤、可以叠层。17:37.715 叠到7层，17:38.690 Âra 圣疗自己，有效治疗614945并回满；紧接着17:38.711 叠到8层，之后继续叠层、继续掉血，17:41.720 才移除。理解：圣疗在不断增强的持续伤害里提供血量缓冲，不能代替终结闪电来源的机制处理。该窗口没有直接核查大斧死亡，不把最后减益移除归因为已击杀斧头。

场景C，吸取生命期间自救：r1 13:46.712 圣疗自己，有效治疗621977并回满。13:47.051、13:48.108 等后续吸取生命仍继续造成伤害，直到13:52.893 才移除减益。结合第1节可见，同类机制下玩家使用过两种不同应对：圣疗补血维持生存，圣盾直接解除自身效果。不能仅凭日志断言两人选择不同是由于冷却、天赋或临时决策。

证据：`lay-ally-boss1`、`lay-self-lightning`、`lay-self-drain` 的 JSON/TXT。血量读自伤害及治疗事件；治疗事件的 resourceActor 也已核对，给队友治疗时使用目标资源，不把施法事件中的施法者血量混用为队友血量。

## 仍不下结论的部分

- 自由祝福：已知实际增益对象，尚缺具体减益解除或机制免疫证据。
- 制裁之锤、盲目之光：还需目标控制生效和读条后续；不把控制施法次数等同于有效应对次数。
- 自律与天赋：有天赋树原始数据，但尚未完整映射影响自律交互的节点；暂不规定圣疗、保护和圣盾的通用连用顺序。
- 样本跨日期，技能说明为采集时可获取版本；上述结论限定于这些实战场景，不把所有行为解释为当下版本的普遍最优策略。
