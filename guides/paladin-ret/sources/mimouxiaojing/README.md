# 密谋小径 · 惩戒骑研究材料

第一版手册的研究材料。现行手册由 `../mimou-v2/build.py` 生成；第一版的 `build.py`/`content.py` 已删除。

## 核对材料

- `research.md`：初筛清单，包含未采用候选技能。
- `combat-findings.md`：代表场景的技能说明与事件还原。
- `audit.py`：离线枚举全部关注技能施法，计算附近敌方施法与技能目标承伤。
- `cast-audit.json` / `.md`：三个报告的96次关注技能施法。不是只抽取代表场景；每次均保留前4秒至后8秒的上下文。
- `coverage.json`：全部施法对应的正文路线章节；不把附近发生自动视为施法原因。
- `spell-reference.json`：按实际敌方事件ID获取的说明；排除了仅仅同名的玩家技能。额外的承伤技能说明在证据包中。
- `evidence/`：初始数据、定向补查、场景窗口与三人的全部圣疗治疗事件。

## 写作边界

正文是攻略，不展示样本名、施法次数、有效治疗数字或核对表。逐次材料只供编辑和复核使用。同类机制合并讲解，三号前后的小怪区均明确提醒。

没有明确机制效果的孤立使用不改写为固定技巧。例如 C26 在转场期给队友保护，附近没有明确敌方技能施法，因此不宣传成“保护免疫坠落”。A09 没有对应成功驱散，不能当作额外一次清毒成功案例。B26 圣疗治疗事件的资源数值超过当时最大生命值，正文只写救援用途，不由该值计算百分比。

成品不包含未经验证的天赋导入串。采用圣佑与复仇之盾联动的建议时，正文明确要求确认实际天赋；不硬写圣疗、保护、圣盾的通用连用顺序。

本次新增补查：所有圣疗的治疗事件、此前场景外敌方技能说明，以及全部关注技能的离线上下文。仍缺逐次站位/视线与完整天赋节点映射；不据此宣称固定站位、固定路线或唯一最优按键顺序。
